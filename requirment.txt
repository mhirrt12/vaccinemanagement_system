# ----- Production Deployment Notes -----
1. Change all default passwords
2. Update CORS headers for production domain
3. Use HTTPS for all connections
4. Set up proper Apache/Nginx virtual host
5. Configure MySQL user with limited privileges
6. Enable PHP error logging (disable display_errors)
7. Set up SSL certificate
8. Configure firewall rules
9. Set up database backups (daily)
10. Use environment variables for sensitive data

# ----- Technologies Used -----
Frontend: React.js, Axios, Bootstrap 5, Chart.js
Backend: PHP (MVC pattern), RESTful API
Database: MySQL (3NF normalized)
Authentication: JWT (JSON Web Token)
Email: PHPMailer with Gmail SMTP
Notifications: Email (3-day + day-of reminders)
